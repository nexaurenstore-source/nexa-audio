# Nexa Audio

**Audio Player by Nexauren**

Nexa Audio is the first Android app in the Nexauren Apps ecosystem.

## V1 goals

- Local audio library
- Play / pause
- Previous / next
- Seek bar
- Background playback
- Notification and lock-screen controls
- Favorites and playlists
- Modern Nexauren interface

## Build

The project uses Android, Kotlin and Jetpack Compose.

The first release will be distributed through GitHub Releases and later listed in Nexauren Apps.
